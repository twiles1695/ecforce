    ecforce 変数一覧¶

    商品詳細ページ¶

    変数 説明
    product.name 商品名
    product.id 商品全体（親）のID（例：Tシャツ）
    product.master.id SKU に対応する商品ID（例：Tシャツ M 赤）
    product.thumbnail.url サムネイル画像の URL
    product.master.thumbnails バリエーション（SKU）ごとの画像（配列）
    product.master.option_values_presentation オプション値を文字列取得
    product.parsed_description 商品説明を HTML 変換したもの
    product.delivery_group_names 配送グループ名リスト
    product.concurrent_purchase_group_names 同時購入グループリスト
    product.concurrent_purchase_badge_names 同時購入用バッジ名のリスト
    product.master.pre_order.is_pre_order? プレオーダー商品かどうか（真偽値）
    product.master.pre_order.pre_ordered_delivery_description 予約商品の「お届け予定時期」説明
    pre_order_settings.notes 予約販売に関する注意事項・メモ
    product.caution 注意喚起文
    product.master.list_price 通常価格（税抜）
    product.master.list_price_inclued_tax 通常価格（税込）
    product.first_price 販売価格（セールなど）
    product.first_price_include_tax 販売価格（税込）
    product.maker.name メーカー名
    product.maker.url メーカーの URL
    product.option01 ～ product.option01 自由入力カスタムオプション（複数可）
    product.product_categories 商品が所属するカテゴリーのリスト
    product.labels 商品ラベル
    product.master.parsed_description マスター SKU の詳細説明
    product.has_co_selling_product? 共同販売商品が紐づいているか（真偽値）
    co_selling_products 共同販売商品オブジェクト
    relation_products 関連商品オブジェクトの配列
    product.extra_text_from_product_category カテゴリに関連する追加テキスト
    reviews 内部的に紐づくレビュー取得
    product.average_star レビュー平均点
    product.recurring? 定期販売かどうか（真偽値）

    商品カテゴリーページ¶

    変数 説明
    category.name カテゴリー名
    category.product_category_visibility 表示可能かどうか（真偽値）

    その他¶

    変数 説明
    enabled_pre_order 予約販売機能が有効かどうか（真偽値）
    valid_pre_order_variant 予約可能なバリエーションかどうか（真偽値）
    base_info.multiple_co_selling_products 複数共同販売商品が許可されているか（真偽値）
    base_info.use_review? レビュー機能が有効かどうか（真偽値）
    current_customer ログインしている顧客の詳細情報
